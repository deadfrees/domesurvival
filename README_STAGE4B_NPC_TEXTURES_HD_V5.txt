DomeSurvival Stage 4B V5 - HD NPC texture patch

NPC mapping:
maneogflow -> expedition_soldier.png
iVan       -> dome_security_officer.png

The two runtime textures are 4096x4096 RGBA PNG.
They are nearest-neighbor upscales from the prepared canonical 64x64
Minecraft Java Classic/Steve UV skins. No interpolation is used.

Install over C:\domesurvival, then run:
  .\APPLY_STAGE4B_NPC_TEXTURES_HD_V5.bat
  .\dev\RUN_DEV_FULL.bat

For already-created NPCs, Reset Script / Apply once if the client still
shows a cached previous texture.
