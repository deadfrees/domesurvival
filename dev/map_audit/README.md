# Аудит карты и план биологических капсул

Актуальный источник анализа: `run/saves/WASTED_TEST`.

## Результат аудита

- Просканирована основная область регионов `-5..5` по X и Z.
- Успешно прочитано 109 601 чанк, ошибок чтения: 0.
- До правки найдено 2 115 контейнеров и 308 подписанных точек/помещений.
- Отобрано 66 подходящих зданий и удалённых объектов.
- Здания распределены по восьми группам лута.
- В 64 точках без подходящего лутового хранилища установлено по одной бочке.
- Варочные стойки, печи, воронки и раздатчики больше не считаются подходящими хранилищами.
- Все 66 выбранных точек имеют настоящий сундук, бочку либо совместимое хранилище.

## Правила размещения капсул

- В одном здании находится не более одной биологической капсулы.
- Для каждого из 23 разрешённых видов предусмотрено две гарантированные точки.
- Две капсулы одного вида расположены не ближе 500 блоков друг к другу.
- 46 зданий заняты гарантированными точками.
- 20 зданий содержат необязательные случайные тайники.
- Случайные находки не заменяют гарантированные пары.
- Каждый дополнительный тайник делает один бросок при первом открытии: 40% на одну капсулу.
- Для найденной дополнительной капсулы шанс повреждения составляет 70%.

Все 46 гарантированных капсул записаны в назначенные контейнеры и повторно проверены чтением NBT мира.
В каждой точке находится не больше одного `domesurvival:bio_module`; предмет хранит `EntityId`, `Damaged`
и `Version=1`. Установщик идемпотентен и отказывается перезаписывать существующий предмет.

Для новых и сторонних карт используется отдельный глобальный модификатор лута и data-driven профили из
`data/domesurvival/bio_module_loot`. Поэтому случайное появление модулей не зависит от фиксированных координат
карты `WASTED_TEST`.

Дополнительные контейнеры фиксированной карты используют ленивую таблицу
`domesurvival:chests/bio_module_cache`: результат определяется только при первом открытии контейнера.

## Основные файлы

- `candidate_sites.json` — 66 объектов, координаты и категории.
- `bio_capsule_placement.json` — гарантированные пары видов и дополнительные точки.
- `data/domesurvival/loot_tables/chests/bio_module_cache.json` — пустая основа случайного тайника;
  капсулу добавляет глобальный модификатор согласно data-driven профилю.
- `output/site_catalog.csv` — итоговый каталог зданий и ближайших контейнеров.
- `output/storage_plan.csv` — подтверждение наличия хранилища в каждой точке.
- `output/storage_install_journal.csv` — журнал изменённых чанков и SHA-256 регионов.
- `WorldMapAudit.java` — read-only сканер регионов и генератор обзора.
- `WorldStorageInstaller.java` — офлайн-установщик, записывающий бочки только поверх воздуха.
- `WorldBioCapsuleInstaller.java` — идемпотентная установка и проверка 46 гарантированных модулей.
- `INSTALL_FIXED_BIO_CAPSULES.ps1` — резервное копирование регионов, установка хранилищ и капсул, затем проверка.
- `VERIFY_FIXED_BIO_CAPSULES.ps1` — повторная read-only проверка капсул непосредственно в файлах мира.
- `VERIFY_MAP_LOOT_PLAN.ps1` — проверка уникальности точек, расстояний и полноты схемы.
