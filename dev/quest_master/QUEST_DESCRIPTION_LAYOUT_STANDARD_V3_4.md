# Quest Description Layout Standard v3.4

Для всей кампании Dome Survival используем единый порядок:

1. Сначала сюжетное и техническое объяснение квеста обычным текстом.
2. Затем в самом низу отдельный блок действий.
3. `◆ Что сделать` — золотой жирный заголовок.
4. Конкретное действие — белым.
5. `◆ Как засчитывается` — бирюзовый жирный заголовок.
6. Автоматическая проверка — серым.
7. Если есть предупреждение: `⚠ Важно` — жёлтым жирным.

Инструкции больше не ставятся сверху и не выделяются CAPS LOCK.

FTB Quests разбирает строки описания через `TextUtils.parseRawText()`, поэтому
для цветных строк используется vanilla raw JSON Component внутри строки SNBT.
