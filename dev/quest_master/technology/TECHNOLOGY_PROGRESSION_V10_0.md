# Dome Survival — технология и изучение рецептов v10.0

## Поведение

- Технологический прогресс общий для всего мира и всей команды.
- Закрытый рецепт не выдаёт результат ни на клиенте, ни на сервере; ингредиенты не расходуются.
- На закрытом предмете показывается причина и название нужной технологии.
- При открытии технологии все игроки получают синхронизацию и сообщение.
- Старые сохранения восстанавливают открытия из уже завершённых глобальных квестов.

## Основная лестница

| Квестовый этап | Что открывается |
| --- | --- |
| Начало энергетической программы | собственная коксовая печь и шахтная плавильня DomeSurvival, инженерный молот, стабилизатор, импульсная матрица |
| Импульсная матрица | угольный генератор |
| Первая запитанная машина | базовые энерготрубы |
| Передача энергии | базовый энергобуфер |
| Энергосистема купола | базовые жидкости, инструменты IE, ранняя линия Mekanism |
| Исследование очистки воды | очиститель воды |
| Исследование электролиза | кислородный электролизёр |
| Исследование электролиза | базовая кислородная труба |
| Производство кислорода | усиленная кислородная магистраль |
| Исследование заправки | заправщик кислорода |
| Заправочная станция | маска и малый переносной баллон |
| Следующие промышленные главы | тяжёлые машины IE/Mekanism/Thermal, автоматизация, космос |

Сырьё, слитки, пыль, пластины, провода и другие базовые материалы не блокируются: игрок всегда может собрать ресурсы для следующего исследования.

Ранние обязательные рецепты не используют тёмную сталь EnderIO: этот сплав требует Alloy Smelter и относится к будущей технологии автоматизации. EnderIO открывается цельным производственным этапом, начиная с Primitive Alloy Smelter.

Ремонтные рецепты стартового шлюза используют собственные инженерные узлы DomeSurvival: стальную, оловянную, свинцовую и никелевую шестерни. Каждая шестерня собирается из четырёх соответствующих слитков и железной втулки после начала энергетической программы. Это сохраняет обязательную сложную выплавку стали, использует ранние руды разных школ и не открывает Thermal целиком. Для ключа дополнительно нужен компас, для панели и ворот — поршневые приводы. Поздние схемы Mekanism для этого не нужны. Начало энергетической программы открывает собственную коксовую печь и шахтную плавильню: уголь с отдельным топливом медленно превращается в кокс, затем железо и кокс — в сталь и шлак. Эта цепочка не требует Незера, электричества, готовой стали или машин Immersive Engineering. Стандартная доменная печь IE остаётся поздним промышленным вариантом. Усиленные магистрали и титановый буфер открываются только вместе с обработкой деша, а не раньше космических материалов.

## Ранняя металлургия и пустынное сырьё

- Коксовая печь и шахтная плавильня занимают два блока по высоте. Верхняя секция уже основания и автоматически устанавливается, синхронизирует рабочую анимацию и удаляется вместе с нижней.
- Коксовая печь требует четыре блока кирпичей, два блока глины, две свинцовые шестерни и ванильную плавильную печь. Суммарно только на огнеупорный корпус нужно 24 комка глины.
- Шахтная плавильня требует два железных блока, два медных блока, оловянную и свинцовую шестерни, два куска кокса и ванильную плавильную печь.
- Возобновляемая глина получается промыванием: восемь блоков песка вокруг ведра воды дают четыре комка глины, пустое ведро возвращается.
- Собственные кокс, стальной слиток и шлак имеют отдельные 16×16 предметные текстуры. Сталь входит в `forge:ingots/steel`, поэтому остаётся совместимой с рецептами сборки.

## Проверка в игре

- `/dometech status` — сколько технологий изучено.
- `/dometech inspect` — проверить предмет в основной руке.
- Администратор может временно менять флаг через существующую команду `/domequest gate set|clear <FLAG>`.
