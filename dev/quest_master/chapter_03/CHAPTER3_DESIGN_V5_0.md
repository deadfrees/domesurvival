# Глава 3 — «Здесь будут жить»

15 квестов. Финальный флаг: `SETTLEMENT_ESTABLISHED`.

Цель главы — превратить стартовый Купол из лагеря в функциональное поселение.

Обязательные зоны:
- склад;
- рабочий угол / workshop;
- медная печь;
- топливный резерв;
- жилая зона;
- освещение;
- контакт с iVan;
- отдельная рабочая зона у внутренней части шлюза.

FTB не дублирует ресурсную линию восстановления мастерской Joseph: квесты
проверяют только обустройство собственной рабочей зоны.

## Автоматические проверки

Ручных checkmark-задач нет.

Сервер отслеживает только события установки блоков и взаимодействия:
- сундук/бочка внутри Купола;
- верстак + камнерез;
- любой block registry path, содержащий одновременно `copper` и `furnace`;
- две кровати любого цвета;
- четыре источника света;
- NPC iVan;
- контейнер + верстак возле внутренней панели шлюза;
- финальный обход через airlock control panel.

Постоянных world-scan нет.
