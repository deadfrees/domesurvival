# Глава 6 — «Пусть горит свет»

Глава 5 «Всё своё не унесёшь» удалена как лишний однотипный этап.
После Главы 4 кампания сразу переходит к энергетике.

20 квестов. Финальный флаг: `POWER_INFRASTRUCTURE_ESTABLISHED`.

Граф: четыре ресурсные ветки сверху, затем одна основная вертикальная линия
`generator -> FE check -> power line -> storage -> storage check -> network ready -> finale`.
Слева и справа только короткие support-ветки освещения и резерва.

Генераторы, проводники и накопители определяются совместимо по registry path,
а generator/storage дополнительно подтверждаются через
`ForgeCapabilities.ENERGY` при взаимодействии.

Airlock control panel остаётся автономным и не требует FE.
