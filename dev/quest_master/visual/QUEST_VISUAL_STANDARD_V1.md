# Dome Survival — Quest Visual Standard v1

## Фон главы
Каждая новая глава получает собственный канонический 16:9 арт-фон одновременно с созданием главы.
Рабочая текстура: 1024×576, затемнённая и слегка смягчённая для читаемости интерфейса.

Активно сейчас:
- Глава 0 «Под Куполом»: ранний жилой Купол, шлюз, деревья, простые рабочие места.
- Глава 1 «Первые дни»: утверждённый пустынный Купол с базовым хозяйством.

Зарезервировано:
- Глава 2: утверждённый пользователем простой Variant 3. Он сохранён в docs, но не подключается до создания самой Главы 2.

## Семантические рамки
- [СЮЖЕТ] — золото, hexagon.
- [СРЕДА] — оранжевый, circle.
- [РЕСУРСЫ] — стально-синий, square.
- [ХОЗЯЙСТВО] — зелёный, rounded square.
- [ШЛЮЗ] — бирюзовый, gear.
- [ПЕРСОНАЖ] — фиолетовый, pentagon.
- [ЭТАП]/[ФИНАЛ] — ярко-золотой, diamond/octagon.

Каждый квест получает ровно один `ds_visual_*` tag, чтобы цветовые селекторы FTB не конфликтовали.

## Что кастомизируется
- цвет рамки открытого окна квеста;
- цвет заголовка;
- цвет Tasks;
- цвет Rewards;
- цвет кнопки для locked/not-started/started/completed;
- цвет dependency lines;
- толщина dependency lines;
- форма квеста;
- размер квеста;
- масштаб иконки;
- цветной semantic badge в subtitle;
- chapter title/accent;
- chapter selected highlight;
- background image.

## Описание
Сохраняется стандарт:
сюжет/объяснение → ◆ Что сделать → ◆ Как засчитывается → ⚠ Важно.

## Будущие главы
Глава не считается визуально завершённой без:
background + accent + semantic tags + shape/size/icon scale + subtitle badge + styled description.


## Hotfix 3.5.1
Фон для уже созданных глав жёстко стандартизирован: `x=-11.0`, `y=-1.0`, `width=32.0`, `height=18.0` (соотношение 16:9).
Подзаголовок каждого квеста теперь хранится как обычная строка, например: `РЕСУРСЫ · Соберите минимум 16 дубовых брёвен.` Это исключает вывод сырого JSON в интерфейсе.


## Hotfix 3.5.3 — размер фона

После визуальной проверки 32×18 признан слишком маленьким.

Новый стандарт для текущих и следующих глав:
`x=-19.0`, `y=-5.5`, `width=48.0`, `height=27.0`.

Это 16:9 и в 1.5 раза больше по ширине и высоте, чем 32×18.
Центр изображения остаётся в той же точке `(5, 8)`, поэтому композиция не
уезжает относительно дерева квестов.


## Hotfix 3.5.4 — subtitle

Отдельный `subtitle` у квестов отключён полностью.

Он дублировал блок `◆ Что сделать`, поэтому больше не используется ни в текущих,
ни в будущих главах. Семантический тип квеста остаётся виден по форме и цвету
рамки, а инструкция — только в нижнем блоке описания.


## Phase 3.6 — настоящий полноэкранный фон

`ChapterImage` больше не используется как фон главы.

Причина: в FTB Quests 1.20.1 ChapterImage является `QuestPositionableButton`.
QuestPanel включает такие объекты в questMin/questMax, поэтому увеличение фона
само увеличивает scroll-world. Из-за этого невозможно получить настоящий
неподвижный фон экрана только увеличением `width/height`.

Новый стандарт:
- фон рисует Dome Survival в `ScreenEvent.BackgroundRendered`;
- фон не участвует в координатах дерева;
- фон не двигается при pan/zoom;
- фон покрывает весь QuestScreen без видимой границы;
- используется режим COVER;
- X/Y никогда не растягиваются независимо;
- излишек только обрезается по краям;
- центр изображения совпадает с центром экрана/центрированной квестовой сетки.

В SNBT `images: [...]` для chapter background больше не создаётся.


## Phase 3.6.5 — правильный слой FTB

Фон главы рисуется в `QuestPanel.drawOffsetBackground()` через client-only
pseudo Mixin. Forge background event используется только для захвата
GuiGraphics.

Канонический порядок:
`FTB BaseScreen background -> chapter art -> dependency lines -> quest nodes`.


## Phase 3.7 — канонический фон главы

Экспериментальный renderer/mixin Phase 3.6.x больше не используется.

Фон главы задаётся штатным свойством FTB Quests:

```text
[CHAPTER_ID]
background: domesurvival:textures/gui/quests/<chapter>.png; color=#FFFFFFFF
```

FTB Quests сам рисует `ThemeProperties.BACKGROUND` на весь QuestScreen.
Это является каноническим способом для всех последующих глав.

`ChapterImage` для фона запрещён: он участвует в quest-space и расширяет
questMin/questMax.

Все тематические изображения главы подготавливаются в 16:9.
