# Automatic action quests — Chapters 0-1

Manual checkmarks больше не являются способом пройти эти квесты.

## Chapter 0
- Под Куполом → игрок фактически находится в безопасной зоне стартового Купола.
- Воздух — часть стены → сервер подтверждает breathable state внутри безопасной зоны.
- За воротами нет воздуха → игрок фактически выходит в OUTSIDE и environment non-breathable.
- Солнце тоже враг → игрок минимум ~1 сек снаружи днём под открытым небом в ясную погоду.
- Погода / проверка условий → игрок использует airlock control panel.
- Джозеф Куппер → реальное взаимодействие с NPC по имени Joseph/Джозеф.
- Найди шлюз → реальное взаимодействие с airlock_gate.
- Навес не атмосфера → игрок минимум ~1 сек снаружи без видимого неба, но воздух остаётся non-breathable.
- Правило возврата → сервер видел игрока OUTSIDE, затем он реально вернулся в safe Dome.
- Финал главы → auto после реального выполнения всех зависимостей.

## Chapter 1
- Первые дни → auto после завершения Главы 0.
- Проверка погоды → реальное использование airlock control panel после подготовки навеса.
- maneogflow → реальное взаимодействие с NPC maneogflow.
- Рабочая зона шлюза → повторная проверка control panel после готового gate-cache и контакта с maneogflow.
- Проверка готовности → игрок стоит в AIRLOCK и реально имеет 1 bucket + 4 bread + 8 torches.
- Финал главы → auto после выполнения зависимостей.

Item quests продолжают выполняться штатным FTB inventory detection и затем
глобально синхронизируются на сервер.
