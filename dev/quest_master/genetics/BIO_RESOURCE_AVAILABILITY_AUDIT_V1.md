# Проверка доступности ресурсов биологической ветки

Источник: `dev/map_audit/output/surface_blocks.csv`, полный аудит фиксированной карты.

## Найденные возобновляемые стартовые ресурсы

- трава: 76 235 блоков — источник семян;
- пшеница: 123 растения;
- морковь: 28 растений;
- картофель: 40 растений;
- сахарный тростник: 19 растений;
- песок: 19 309 758 блоков — стекло и глина через песчаное сито;
- костяные блоки: 362 блока, дополнительно к костям со скелетов.

## Ненадёжные ресурсы, исключённые из обязательной прогрессии

- ламинария отсутствует в аудите;
- кактус отсутствует в аудите;
- слизь представлена только шестью блоками слизи и не считается возобновляемой;
- мёд требует уже восстановленных пчёл и создаёт циклическую зависимость;
- бамбук, тропическая рыба и растения Нижнего мира не подходят для общей ранней ветки.

## Принятое решение

- Биогель производится из глины, костной муки, сахара и стеклянной бутылочки.
- Питательная смесь производится из пшеницы, моркови, картофеля и костной муки.
- Все виды в биоинкубаторе используют универсальную питательную смесь. Расход зависит от
  редкости и размера вида: 2–3 для обычных, 4 для необычных, 6 для редких, 8 для особых.

Так исключены биомные и циклические тупики: для восстановления пчелы больше не требуется
мёд, для лягушки — слизь, для панды — бамбук, для аксолотля — тропическая рыба.
