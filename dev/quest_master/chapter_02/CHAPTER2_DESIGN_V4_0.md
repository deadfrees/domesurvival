# Глава 2 — «За воротами»

17 квестов. Канонический флаг завершения: `FIRST_SUPPLY_RUN`.

## Роль главы

Это первая глава, где игрок системно выходит наружу, но ещё **без переносного
кислорода и без кислородного производства**.

Игрок обучается циклу:

`подготовка -> проверка панели -> короткий выход -> ориентир -> возврат -> груз -> закрытие операции`

Жёсткие ограничения ранней главы:

- никаких дальних структур;
- никаких ночёвок;
- никаких deep mining expeditions;
- никаких задач на 250–350+ блоков;
- рабочий предел кода: не дальше 75 блоков от центра стартового Купола,
  то есть примерно 25 блоков за его внешней стеной;
- контрольный возврат: до ~20 секунд снаружи.

## Автоматизация

Ручных checkmark-задач нет.

Сервер автоматически наблюдает:

- выход из безопасной зоны;
- достижение ближнего периметра;
- установку факела;
- установку 4 блоков булыжника;
- длительность и максимальную дальность sortie;
- повторные успешные возвращения;
- возвращение с 16 песка;
- pre/post-check панели шлюза.

Все такие задачи используют hidden `minecraft:impossible` advancements, как в
Главах 0–1.

## Глобальная награда

Сохраняется правило Phase 3.2:

- прогресс квеста глобальный для сервера;
- награда одна на весь сервер;
- получает её игрок, чьё действие первым завершило квест;
- остальные игроки получают только mirrored completion.
