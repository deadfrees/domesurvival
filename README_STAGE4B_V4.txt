DomeSurvival Stage 4B V4 — final NPC skin patch

USES THE APPROVED SKIN DESIGNS ABOVE:
1. maneogflow — military/camouflage operator skin
2. iVan       — black tracksuit / sunglasses skin

Both texture files are real Minecraft Java 64x64 Classic/Steve skins.
All base body UV faces are opaque and present. Overlay transparency is used only
for raised details such as sunglasses, cap/vest, cuffs and boot/knee details.

Texture resource paths:

INSTALL:
1. Expand this ZIP over C:\domesurvival
2. Run:
   .\APPLY_STAGE4B_NPC_SKINS_V4.bat
3. Start:
   .\dev\RUN_DEV_FULL.bat
4. On each already-created NPC, open NPC Scripter and press Reset Script/Apply
   once so init() refreshes the name, position and skin.
