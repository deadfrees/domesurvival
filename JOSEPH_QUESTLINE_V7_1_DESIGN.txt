DomeSurvival — Joseph Kupper Questline V7.1
===============================================

Design goal
-----------
The first chapter now follows the survival logic of the dome:
survive inside -> restore workshop -> stabilize power -> purify water ->
build oxygen infrastructure -> first serious outside expedition ->
automate logistics -> create an emergency reserve.

Stage 02 remains the only large automatic construction event: the existing
workshop restoration through JosephCooperBridge/WorkshopUpgradeApplier.
Stages 03-08 do NOT place structures or touch dome/world blocks. Their
"base upgrades" are progression states plus useful infrastructure reward packs.

Shared progression / rewards
----------------------------
Quest progress remains in CustomNPCs world StoredData, as in the current
Joseph GUI. Reward keys use the same stageXX prefixes, so admin reset removes
them too. Each reward pack is one-time for the shared base; the player who
finishes the stage physically receives the package and can install/distribute it.

Testing an existing WASTED_TEST
-------------------------------
Use:
  /josephscript apply
  /josephscript resetprogress

resetprogress is preferred for this test because it resets logical quest state
while preserving an already-built workshop.

Do NOT use resettest unless you explicitly want the physical workshop removed
and rebuilt during Stage 02.
