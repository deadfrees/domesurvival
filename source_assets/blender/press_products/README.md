# Изделия металлообрабатывающего станка

24 результата существующих рецептов `data/domesurvival/recipes/forming`:
пластины, шестерни, стержни, проволока и трубки восьми материалов.

Игровой формат — `minecraft:item/generated`, обычный плоский предмет, как слиток.
Никакой геометрии `elements` или увеличенных трансформаций в игровых JSON нет.
Blender-геометрия служит только исходником для запекания иконок.

Стиль: 32×32, ограниченная палитра, чёткая альфа, тёмная пиксельная окантовка,
крупные фаски и спокойные блики. Фотореалистичной фактуры и размытия нет.
Цвета материалов сохранены: медь — рыжая, сталь — серая, олово/серебро — светлые,
никель — тёплый, свинец — серо-фиолетовый, готеий — бирюзовый, вольтарий — фиолетовый.

Воспроизведение из корня проекта:

```powershell
& 'dev/fluid_pipes/runtime_blender/blender.exe' -b -t 6 -P source_assets/blender/scripts/create_press_products.py
powershell -NoProfile -ExecutionPolicy Bypass -File dev/forming_press_v2/preview_products.ps1
```

Скрипт получает перечень предметов из рецептов; рецепты, баланс и идентификаторы
не меняет. Текстуры записываются в отдельный каталог `textures/item/press_products`.
Общий исходник — `press_products.blend`, таблица предпросмотра — `overview.png`.
Таблица показывает каждую иконку в масштабе 3× и в исходных 32 пикселях.
