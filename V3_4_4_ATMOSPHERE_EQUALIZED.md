DomeSurvival V3.4.4 - Atmosphere Equalized
==========================================

Changes requested after V3.4.3 testing:

- Sandstorm colour/tint inside the dome is now identical to the outside storm tint.
- The dome still protects from sandstorm damage; only the visual atmosphere is equalized.
- Acid rain green atmosphere is significantly stronger.
- Acid rain fog now uses the same density inside and outside the dome.
- Acid thunderstorm fog now uses the same density inside and outside the dome.
- Acid rain keeps ~82% of the current clear-weather far plane.
- Acid thunderstorm keeps ~72% of the current clear-weather far plane.
- Sandstorm visibility behaviour is unchanged: the storm remains the strongest visibility hazard.
- Screen colour grading for rain/thunder/sand is now equal on both sides of the dome glass.
- Oxygen implementation is not modified.

Goal
----
The glass dome is a physical protection barrier, not a visual weather cancellation barrier.
Players inside should clearly perceive the same toxic green / orange exterior atmosphere while
remaining protected from the environmental damage.
