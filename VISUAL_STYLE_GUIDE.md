# DOMESURVIVAL — визуальное направление, прототип 01

Статус: предложение для оценки на одной станции регенерации фильтров. Массовая миграция ещё не начата. Основание — текущее рабочее дерево, `ASSET_AUDIT.md`, аудиты кода и ограничения существующих capabilities.

## Характер

Оборудование обитаемого купола: ремонтопригодные металлические корпуса, сменные кассеты, тёмные уплотнения и небольшие сигнальные лампы. Износ сосредоточен на кромках и ручках. У каждой машины один узнаваемый рабочий узел; сервисная арматура вторична. Фильтровальная кассета, двигатель и бак должны отличаться силуэтом и компоновкой.

За основу взята уже присутствующая в проекте графитовая промышленная палитра регенератора и GUI. Для первого образца используются существующие 16×16 материалы `filter_regenerator_*`, а для более читаемого корпуса и кромок — `hopper/steel_body` и `hopper/steel_rim`. После первого просмотра в Minecraft исходный металл регенератора оказался слишком тёмным. PNG не изменены: переработаны геометрия, UV и привязки материалов.

## Палитра и значение

| Роль | Базовый цвет | Правило |
|---|---|---|
| Корпус | `#596361` | Средний серый, читаемый при стандартном освещении |
| Каркас | `#303A3B` | Тёмный металл, занимает меньшую площадь, чем корпус |
| Уплотнение / углубление | `#171E20` | Тень в пазах; не заливать всю лицевую сторону |
| Светлая кромка | `#8F9990` | Один пиксель; без глянцевого градиента |
| Энергия | `#C5A252` | Охра + контактный знак |
| Кислород | `#68B8C7` | Голубой + круглый разъём / символ газа |
| Жидкость | `#527FA8` | Синий + капля |
| Тепло | `#C17C4D` | Приглушённый оранжевый + штрихи тепла |
| Работа / восстановление | `#79AC88` | Зелёный только при подтверждённой работе |
| Предупреждение | `#CB9360` | Цвет + понятная надпись / форма |
| Выход предметов | светлый шеврон | Направление важно больше цвета |

Цвета — цели для будущей палитры, а не утверждение, что все старые PNG уже содержат ровно эти RGB. Не добавлять кислородный или жидкостный разъём машине, у которой нет соответствующей capability. Цвет никогда не является единственным способом распознать состояние.

## Геометрия, текстуры, масштаб

- 16 model units = 1 блок. Обычный корпус занимает 16×16×16; углубления 0.5–1 unit дают читаемый рельеф.
- Основная плотность — один пиксель на model unit. Для крупных деталей допускаются 32×32 или атлас 64×64 с той же плотностью; 128×128 только по измеренной необходимости.
- Однопиксельные болты и маркировку рисовать текстурой. Геометрия нужна для рам, кассет, ножек, портов и движущихся частей.
- Не увеличивать все UV до целой текстуры на каждой узкой грани: UV обрезается по физическому размеру детали. Повторять материал на одинаковых креплениях.
- Никакого bilinear-размытия, PBR, shader-only подсветки или обязательной новой зависимости. Статические модели остаются vanilla JSON.
- Число граней измеряется после удаления полностью скрытых граней. Ориентир среднего одноблочного корпуса: около 200 quad-граней, без отдельного BER, если эффект решается blockstate и атласной анимацией. У образца 218 quad: дополнительные грани нужны пяти настоящим утопленным гнёздам и выходному шеврону.
- Габариты, collision и occlusion оцениваются отдельно. Обрамление должно сохранять наружную границу существующего полного блока.

## Проверка читаемости

Проверить фасад на расстоянии 2, 8 и 16 блоков, рядом с vanilla iron block и соседней машиной. Проверить слот 16×16, GUI, JEI, обе руки, dropped item и item frame. На расстоянии должны читаться три уровня: корпус → рабочий узел → индикатор. Болты не должны конкурировать с ними.

## Порядок применения

1. Эталон `domesurvival:filter_regeneration_station` и сравнение OLD/NEW.
2. Оценка пользователем формы и палитры после демонстрации.
3. Машины энергии и кислорода; затем остальные машины.
4. Все 13 труб на существующих directional properties.
5. Wearables с существующими Curios-слотами и vanilla-анимацией.
6. Общие GUI-примитивы, состояния, финальная проверка производительности.

Документы описывают направление для последующих этапов; они не означают, что эти этапы уже реализованы.
