# DOMESURVIVAL — конструкция машин

Статус: стандарт для первого образца и дальнейшего согласованного применения. Единицы — Minecraft model units, 16 = 1 блок.

## Конструктивный стандарт

| Элемент | Размер и правило |
|---|---|
| Наружная оболочка | 1 unit; полный внешний габарит 0..16 сохраняется для обычного полного блока |
| Рама фасада | 1–2 units; тёмный металл, светлая наружная кромка |
| Сервисная кассета | Углубление 0.5–1 unit; собственная рамка и ручка, один крупный узнаваемый узел |
| Опоры | Нижний пояс высотой 2 units; отдельные ножки только если это согласуется с существующей collision |
| Вентиляция | 1-pixel щели на материале или 2–4 крупных ламели; не делать десятки мелких cuboid |
| Болты | 1 pixel в UV; геометрические болты только у крупных узлов |
| Разъём | Центр грани `(8,8)`, зона 6×6; наружная рамка, утопленная 4×4 вставка, контакт |
| Дисплей | Небольшая тёмная вставка; 2–3 светлых пикселя состояния, без нечитабельного микротекста |
| Предупреждение | Узкая полоса охры, максимум одна заметная полоса на фасаде |
| Вход | Стрелка к центру контакта; предметы — светлая метка, энергия — охра |
| Выход | Шеврон наружу; не использовать знак выхода на входной capability |

## Порты следуют коду

Новая модель не создаёт новые направления подключения. Для каждого блока перед рисованием фиксируется таблица `getCapability` и rotation. Локальный NORTH — фасад. Blockstate поворачивает всю модель вместе с маркировками. Для труб используются существующие `north/east/south/west/up/down`, multipart-сегменты и текущие маски отключения.

| Регенератор фильтров | Предметы | FE |
|---|---|---|
| NORTH / фасад | Нет | Нет |
| SOUTH / задняя | Вход | Вход |
| EAST / правая | Вход | Вход |
| WEST / левая | Вход | Вход |
| UP | Вход | Вход |
| DOWN | Выход готового/исчерпанного фильтра по текущим правилам | Нет |

На четырёх входных гранях образца используются одинаковые комбинированные гнёзда. Нижний разъём отличается светлым выходным шевроном. Фасад содержит кассету и лампу; газовые/жидкостные порты на нём отсутствуют. Обозначения не меняют автоматизацию: фильтр восстанавливается в том же слоте, сорбент расходуется из второго.

## Различимость машин

| Семейство | Главный узел | Вторичный признак |
|---|---|---|
| Регенератор | Двойная кассетная решётка | Зелёная рабочая лампа и сменный модуль |
| Генератор | Мотор / топочная камера | Охра энергии, выпуск и охлаждение |
| Электролизёр | Два вертикальных рабочих сосуда | Синий вход воды, голубой газовый выход согласно коду |
| Наполнитель | Крепление съёмного баллона | Клапанный блок |
| Очиститель воды | Фильтровальная колонна | Сервисная крышка |
| Пресс | Поперечина и рабочий зазор | Направляющие / ограниченная анимация |
| Сито | Подвижная сетка | Существующий BER, сохранение стороны выхода |
| Солнечная панель | Фотоячейки и шарнир | Размер соответствует текущему tier, сохранение связности |
| Буфер | Пакет аккумуляторных ячеек | Различимость tier количеством секций, не только цветом |

## Экспорт и производительность

Редактируемый источник: `source_assets/blockbench/machines/filter_regeneration_station.bbmodel`. Финальный формат: vanilla block JSON; active-модель наследует геометрию и заменяет только текстуры состояния. Item наследует тот же корпус с явными display transforms. Точки вращения сохраняются в именованных деталях master-файла, но механическое движение не добавляется без реальной потребности.

Для образца достаточно существующей атласной анимации кассеты/лампы при `active=true`: нет новых tick handler, BER, сетевых пакетов или текстур. Атлас обновляет кадры глобально, даже когда модель не показана; дополнительный расход измеряется как включённые малые sprite, а не обещается как нулевой. Idle использует статические PNG.

Сравнение обязано содержать количество cuboid, quad и triangle, размер PNG/кадра, внешние габариты, UV, перечень runtime-изменений и реальные результаты проверки. Не выдавать статический валидатор за проверку в Minecraft.
