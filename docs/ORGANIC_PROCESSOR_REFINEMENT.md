# Биосинтезатор / organic_processor

Сохранены ID машины, три рецепта, количество ингредиентов, воды и базовая стоимость
циклов. Корпус использует графитовый атлас семейства генератора и пресса.
Внутри — широкая камера, вертикальный вал, два уровня лопастей и верхний привод.
Исходник Blender: `source_assets/blender/organic_processor/organic_processor.blend`.
Генераторы модели и GUI находятся в `source_assets/blender/scripts/`.

Движущаяся часть содержит семь кубоидов и вращается вокруг вертикальной оси
`(8, y, 5)` в координатах модели 16×16×16. Клиентская анимация идёт только при
серверном ACTIVE, останавливается при паузе и использует тот же экспорт в GUI/JEI.
Предмет в инвентаре содержит полную неподвижную сборку. Углублённый корпус не
скрывает грани соседних блоков.

GUI 220×266: основная панель, внутренние вкладки сторон и модулей. Шкала FE
обрезается по уровню с постоянным размером делений, вода использует текстуру
зарегистрированной очищенной воды. Значения и причины остановки доступны при
наведении. JEI 180×128 показывает ту же модель, движение, ингредиенты с точными
количествами и прогресс. Удалена прежняя дублирующая категория из compat/jei.

Лицевая сторона закрыта для автоматизации. INPUT принимает два ингредиента,
очищенную воду и FE; OUTPUT выдаёт только готовый продукт. OFF и запрос без
стороны не открывают обходной доступ. Ранее полученные обработчики повторно
проверяют режим при каждой операции. Настройки следуют относительным сторонам
при повороте ключом и повторной установке.

Два слота поддерживают прежние модули: буфер +75%, экономия −20% FE/−10% скорости,
разгон +35% скорости/+60% FE. Экономия и разгон несовместимы. Начатый цикл сохраняет
свои длительность и стоимость при смене модулей; следующий использует новые.
Снятие буфера при запасе свыше 50 000 FE заблокировано. Значения GUI передаются
двумя 16-битными частями, включая полную ёмкость 87 500 FE.

Ключ снимает один предмет в мир с инвентарём, водой, FE, модулями, сторонами и
прогрессом. При обычной добыче содержимое и модули выпадают отдельно. Для блока
добавлены теги кирки и каменного уровня, как у предыдущей машины.

## Проверка

Игровой прогон: **518 PASS, 0 FAIL**. Визуально проверены основной экран и вкладки
при масштабе 2/3, модель в мире и две последовательные фазы JEI; элементы не
перекрываются, прогресс меняется внутри своей рамки.

Изолированный клиентский прогон:
`powershell -NoProfile -ExecutionPolicy Bypass -File dev/organic_processor_v2/run_review.ps1`.
Он использует отдельный мир и возвращает временно перемещённые моды в `finally`.
Проверки: три рецепта с тремя вариантами модулей, точный расход, паузы, старый NBT,
смена модулей в цикле, все стороны/режимы/ориентации, симуляция передачи, сохранение
и снятие реальным ключом, шесть уровней кирок, сетевые GUI и JEI.

Сборка: `gradlew.bat test build --offline --console=plain`
через `dev/organic_processor_v2/build_release.ps1`.
Проверка ресурсов/JAR: `dev/organic_processor_v2/verify_release.py`.
Результаты и снимки находятся в `dev/organic_processor_v2/runtime/`;
итоговый отчёт — `dev/organic_processor_v2/release_validation.json`.

Реализация выполнена основным агентом. Попытка вызвать visual_designer завершилась
лимитом доступности; результаты специалиста не использовались. Перед переходом
к биоинкубатору требуется оценка внешнего вида пользователем.
