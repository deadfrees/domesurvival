# Шкалы доработанных машин

Исправлены шкалы топлива медной, коксовой и шахтной печей, а также энергии
очистителя воды, электролизёра, кислородного наполнителя и регенератора фильтров.
Общий `client/gui/MachineGaugeRenderer` рисует полную текстуру шкалы с постоянными
размерами, открывая только заполненную нижнюю часть. Размер делений не зависит
от текущего запаса или ёмкости после установки буферного модуля. Пустые значения
и нулевая ёмкость не рисуют заполнение; переполнение ограничивается рамкой.
Эталонные шкалы генератора и пресса сохранены.

В `SandSieveScreen` сплошная голубая заливка заменена анимированной ванильной
текстурой воды с её цветом. Спрайт повторяется без растяжения, края и текущий
уровень обрезаются по внутренней области резервуара. Размеры GUI и слоты прежние.

Изменена только клиентская отрисовка. Механика топлива, энергии, модулей,
синхронизация значений и сохранения не менялись. Работа выполнена основным
агентом без субагентов.

Проверка: `dev/machine_gauges/run_review.ps1` открывает все семь настоящих
экранов с управляемыми значениями данных меню. Она сравнивает пиксели шкал
с пустой и полной шкалой при 25% заполнения, увеличенной ёмкости, полном
увеличенном буфере и нулевой ёмкости. Отдельно сохраняется экран просеивателя
с водой. Проверочные классы подключаются только к изолированному игровому запуску.

Игровой прогон: 29 проверок отрисовки, 0 ошибок. Снимки всех уровней находятся
в `dev/machine_gauges/runtime/`; сравнение выполняется после отрисовки кадров,
чтобы догоняющие клиентские тики не захватывали старое изображение.
